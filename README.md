# RabTech Task 04 — Advanced SQL Queries, CTEs & Window Functions

Retail Sales Analysis System using PostgreSQL.

## Files
- `schema.sql`: creates five related tables.
- `seed_data.sql`: inserts sample records.
- `queries.sql`: contains 14 analytical queries.
- `docs/expected_outputs.md`: describes expected query results.

## Tables
`customers`, `categories`, `products`, `orders`, and `order_items`.

## Run order
1. Create a PostgreSQL database.
2. Run `schema.sql`.
3. Run `seed_data.sql`.
4. Run `queries.sql`.
5. Compare results with `docs/expected_outputs.md`.

Note: This project uses PostgreSQL. Expected-result descriptions are not proof of execution.
