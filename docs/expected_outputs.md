
# Expected Output Guide

Run the SQL scripts in this order:
1. schema.sql
2. seed_data.sql
3. queries.sql

| Query | Expected Result |
|---|---|
| Q1 | Revenue for each non-cancelled order |
| Q2 | Total revenue for every customer |
| Q3 | Five generated month dates |
| Q4 | Orders numbered newest first |
| Q5 | Products ranked by units sold |
| Q6 | Customers ranked by revenue |
| Q7 | Monthly revenue comparison |
| Q8 | Next order date for each customer |
| Q9 | Cumulative revenue for each customer |
| Q10 | Purchased products with customer details |
| Q11 | Products that were never ordered |
| Q12 | Customers from Coimbatore and Chennai |
| Q13 | Products priced above average |
| Q14 | Customers earning above-average revenue |

These are expected-result descriptions. Actual outputs should be verified by running the SQL scripts in PostgreSQL.
